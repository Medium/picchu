Picchu is a Medium-internal Kubernetes operator (kubebuilder v2, controller-runtime v0.22, Go 1.25.5) that drives progressive multi-cluster deployments. It owns five CRDs (Cluster, ClusterSecrets, Revision, ReleaseManager, Mirror) and synthesises downstream resources via a Plan/Applier pipeline funnelled through a single CreateOrUpdate type switch over k8s + Istio + KEDA + WPA + Prometheus-Operator + Sloth + external-secrets + datadog-operator kinds. Revisions drive an 18-state machine per target. Active 2026 architectural focus: Istio ambient mesh + KEDA-scaled waypoints.

**Start with [README.md](./README.md)** for the operator overview, CRD schemas, and runbook docs.

## Gotchas

- scaleRevision.go / ramp logic is historically unstable — 6+ reverts since 2019, four of them in Jan-Feb 2026 (#594->#596, #597->#599, #600->#601, plus historic #144/#281). Treat any change here as high-risk and prefer adding test coverage before shipping. Successful 2026 strategy: small incremental PRs (#611-#617).
- controller-runtime/k8s upgrades have failed twice (Sep 30 2024 #435 reverted by #439 within 2 days; Jun 9 2025 #534 reverted by #536 within 1 day). The successful Jan 2026 upgrade (#583) required removing the KEDA replace directive in go.mod.
- api/v1alpha1/revision_webhook.go has 5 unfilled TODO(user) markers (lines 58, 136, 148, 165, 176) from the Apr 2023 Operator-SDK V1 migration. Default() and ValidateCreate/Update/Delete are no-op scaffolding — Revision admission is effectively unvalidated.
- slack/slack_api.go:114/133 still sends canary alerts to hardcoded channel #eng-fredbottest (C02EKA9SB). After Datadog SLO removal (#549), Slack is the primary canary signal — this channel selection is load-bearing.
- controllers/schedule/schedule.go holiday list ends at 2024-01-01 (~16 months stale). The HumaneReleasesEnabled gate at controllers/incarnation.go:610-613 silently treats every modern US holiday as a workday.
- controllers/utils/api.go:29 RemoteClient cache lookup uses 'client.ObjectKey{}' (zero value) instead of the actual key parameter — every call misses, every reconcile builds a fresh remote client + informer. Informer leak / OOM risk on long-running operator processes with many clusters.
- 8+ explicit panic sites turn recoverable conditions into operator crashloops: main.go:123 (Prom init), main.go:133 (Slack init), releasemanager_controller.go:310 ('Defaults werent set'), revision_controller.go:361 (too many ReleaseManagers), syncer.go:654 ('Assertion failed'), schedule.go:27 (tzdata missing), and controllers/utils/api.go MustGetKind/MustExtractList family (5 sites).
- context.TODO() is used in 13 sites across cluster_controller.go and revision_controller.go instead of the reconcile context. Cancellation and deadlines from controller-runtime are bypassed; slow Prometheus or remote-k8s calls cannot be cut on shutdown.
- proactiveRampMinReplicas (controllers/incarnation.go:485-500) only fires when State == releasing. This is intentional but easy to break: extending the function to other states will raise HPA min on retiring/failing revisions still draining traffic.
- Ambient<->sidecar transition uses a 'transitionToSidecar' flag in controllers/syncer.go. The fallback branch (line 158) uses the newest Revision's preference when all replicas == 0 — surprising behavior during canary of a mesh-mode change.
- Waypoint HPA silently overrides MinReplicas < 2 (controllers/syncer.go:181-189 and effectiveWaypointHPA at 247-254). User WaypointHPA with MinReplicas < 2 is overridden to 2; default 20 max + 70% CPU.
- Shared-PSL lifecycle (post 97d6e64) lives entirely in `ResourceSyncer.syncServiceLevels` (syncer.go:531): >0 enabled SLOs from the first releasable incarnation → sync; otherwise → delete-by-name. `cleanupLegacyServiceLevels` and `syncTaggedServiceLevels` no longer exist; legacy per-tag PSLs are deleted incarnation-scoped via `deleteTaggedServiceLevels` from state handlers.
- The shared-PSL name `{app}-{target}-servicelevels` is built only by SyncServiceLevels.serviceLevelName; DeleteServiceLevels is selector-based ({app, target}, no LabelTag) so there is no name to drift (FM-PICCHU-032 resolved 2026-06-11). (FM-PICCHU-033 about is_grpc was retracted as a false positive — the flag IS read per-SLO.)
- On full teardown, `ResourceSyncer.sync` self-deletes the ReleaseManager at syncer.go:48 BEFORE syncServiceLevels runs — the shared PSL (no OwnerReference) is orphaned; the delete path is unreachable on teardown (FM-PICCHU-034).
- The controller-level shared-PSL lifecycle (sync-vs-delete decision, thrashing regression, Enabled=false filtering) has NO test coverage — only the plan-level SyncServiceLevels/DeleteServiceLevels unit tests exist. The exact race PLT-2119 fixes is untested at syncer level.
- Waypoint HPA default constants (min=2/max=20/cpu=70%) are duplicated as independent literals across controllers/syncer.go and controllers/plan/ensureWaypointHPA.go with no shared source — a future change to one and not the other silently desyncs the defaults.
- EnsureWaypoint.Apply's hand-rolled Gateway diff (specMapsEqual) only compares a fixed allow-list of keys, so a future field added to the Gateway spec would silently never get applied to already-reconciled clusters.
- controllers/plan/ensureWaypointHPA.go and ensureWaypointPDB.go have ZERO test files despite being touched in the 2026-07-28 change window (new gap found 2026-07-30).
- Many Datadog/canary fixes were shipped as 'add temp logging' commits that were later reverted (Jan 23 #449->#450, Feb 20 #477->#480 and #478->#479, Apr 28 #524->#528, etc.). Be skeptical of logging-only changes that linger — likely abandoned debug attempts.
- NewSlackAPI returns (nil, nil) on empty SLACK_TOKEN; main.go's `if errorSlackAPI != nil` check is false and a nil interface holding a nil pointer is passed into RevisionReconciler. The first canary alert nil-derefs deep in a controller-runtime goroutine.

## Key Decisions

- 2026-06: First PLT-2119 cut deleted the shared PSL from per-incarnation Deleting/Failing state handlers — one failing incarnation blinded the others (prometheus rule thrashing). Lifecycle centralized in ResourceSyncer.syncServiceLevels with full-collection visibility; generalized into the SCOPE invariants. (Eduardo Barth)
- 2026-06: DeleteServiceLevels with a `LabelTag: ""` selector was a silent no-op (absent label ≠ empty string); switched to delete-by-name. Enabled=false now filtered at the source so PSL, SLO rules, and ServiceMonitors stop observing uniformly. (Eduardo Barth)
- 2026-05: Per-tag PSLs created churn and orphaned SLO objects; consolidates into a single shared PSL per app/target while preserving tag granularity in SLI queries. (Eduardo Barth)
- 2026-05: Waypoint proxies need their own scheduling preferences; soft requirement avoids blocking when nodepools are saturated. (David Osemwengie)
- 2026-05: Same-day revert: removing waypoint anti-affinity caused co-location and PDB eviction problems. Anti-affinity must stay. (David Osemwengie)
- 2026-05: Different clusters have different traffic profiles; waypoint sizing belongs on the Cluster CR rather than Revision. (Eduardo Barth)
- 2026-04: KEDA-scaled workloads were treated as fixed-size, causing wrong ReplicaSet target counts during ramp. (Dan Benson)
- 2026-04: Load-based HPAs were keeping replicas at Scale.Min during ramp; CanRampTo blocked. Operator now proactively raises HPA min — limited to State==releasing. (Dan Benson)
- 2026-04: CanRampTo was requiring more pods than Scale.Max allowed, stalling ramps indefinitely. (Dan Benson)
- 2026-04: proactiveRampMinReplicas must only fire during release; otherwise it raises HPA min on draining revisions. (Dan Benson)
